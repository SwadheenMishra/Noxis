# Contributing to Noxis

Thanks for your interest! Noxis is **open source but not open to code
contributions**: pull requests won't be merged. This keeps the project's
copyright with one person, so its licensing stays simple.

You can still help a lot:

- **Report bugs.** Open an issue with your OS, Python version, the command you
  ran, and what you expected versus what happened. Remove anything private from
  the output (IP addresses, MAC addresses, device and network names) before
  posting.
- **Suggest features.** Ideas, device fingerprints Noxis gets wrong, and new
  things worth detecting are all welcome as issues.
- **Share feedback.** Tell me what was confusing, noisy or missing in a report.

Please don't attach patches or code to issues. Describe the problem or idea in
words and I'll write the fix myself.

## Security issues

Please don't report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting on this repository instead.
